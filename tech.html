Computers

MacBook Pro M1

daily driver

Daily driver for coding, writing, and browsing. Great battery, still years of updates left and plenty fast enough for the random things I use it for. If I were to buy a new Mac now, I'd probably get an Air for portability because I really don't need the power/fan of a pro. I would like an oled display with 120hz though....

ThinkPad T14s Gen 2 (AMD)

fedora linux

AMD Ryzen 7 PRO 5850U (8C/16T), 16GB DDR4, 512GB NVMe SSD. Installed Fedora on it. Nice laptop for the price (paid $250 on eBay). My only complaint is that the speaker is tinny and horrible, and the display is only serviceable.

Ubuntu Server ("panda")

24/7 homelab

Intel Core i5-7500 @ 3.40GHz, NVIDIA GeForce GTX 1060 6GB, 16GB RAM, 500GB NVMe + 1TB HDD + 16TB Plex storage (2x 8TB). Old gaming PC (PowerSpec G221) turned 24/7 Ubuntu server running Plex and Antigravity.
